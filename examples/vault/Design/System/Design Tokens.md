# Design Tokens

Semantic tokens, light and dark. Source of truth is Figma variables; this note is the human-readable mirror.

```json
{
  "color.bg": { "light": "#FFFFFF", "dark": "#141318" },
  "color.text": { "light": "#1C1B22", "dark": "#F2F1F6" },
  "color.accent": { "light": "#6E56CF", "dark": "#A08DFF" },
  "radius.md": 8,
  "space.4": 16
}
```

Changes go through the [[Button]] and [[Input Field]] components first.
