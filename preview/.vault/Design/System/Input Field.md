# Input Field

Text input with label, helper, and error slot. Validation happens on blur.

- Height 36, radius 8, 1px border `--border`
- Error: border `--danger`, helper turns red, icon on the right
- Never shift layout when an error appears — reserve the helper line

Pairs with [[Button]] in forms. Copy rules for errors live in [[Error States]].
